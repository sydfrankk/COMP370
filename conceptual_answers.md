What is refactoring? Give three examples of refactoring techniques.
	- Refactoring is the process of reorganizing your code without actually changing the functionality. Usually, this is done to make code more readable/make more sense, deepen your own understanding of the code as a program, and highlight your thinking patterns that you went through while solving the problem. 
	- 3 examples of refactoring techniques include:
		- Formatting code into functions 
		- Changing variable names or data types
		- Simplifying/separating logic when applicable 

In a data science project, why does code naturally go through “phases” of messiness?
	-  Code naturally goes through "phases" of messiness because that is the nature of data itself: it is not always neat and tidy. Also, if we are taking various approaches to solve a problem until we get the right one, this is obviously an iterative process, which adds to the messiness. Going back and forth between steps and aspects of a problem can become convoluted, so it is important that we have a good understanding of why we are doing certain things.
